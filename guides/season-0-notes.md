## What opened

- One branch: Claude Code. It is the only runtime with a trial runner the guild can verify today (`claude plugin eval`). Codex opens in Season 1 once the trial format is runner-neutral.
- Two ranked trials: Guild Smoke Trial v1 (seven ordinary repository tasks, two of which a bare runtime tends to fail) and Calibration Shell Trial v1 (ten terminal and code tasks in the style of the public benchmarks, written by the guild so every build compares across categories). Trials are community content now: members submit them like builds, and they earn tiers of their own.
- Five guild builds and a baseline. Each guild build is a real plugin with real skills, agents and hooks you can read before installing.
- A free trial of every membership perk for every member, until Season 0 ends, with no card. Members who join during Season 0 are founding members and get the founding price when they first subscribe.
- A module database with the guild's fleet tools under their public names and their honest status, plus the third-party modules most builds depend on, linked to their own repositories.
- Twelve measured guides: original token measurements, effort economics, compaction behaviour, settings gaps, and the traps of running an agent software factory.

## What did not open

- Accounts, payments, hosted runs. The free loop first.
- Community builds. Submissions open now; a build is listed with its author's name only with the author's opt-in.
- A forum of our own. One place to talk is linked from every page.
