# Contributing to Guild

1. Fork this repository and make a branch for your change.
2. Keep to one guide, or one change to the rules, per pull request.
3. A guide is `guides/<slug>.md` with a kebab-case slug and the front matter listed in [`README.md`](README.md). Lead
   with the answer, and give the source of every number.
4. buildguild.gg refuses to build with a guide whose front matter is incomplete, so a maintainer builds the site with
   your change before merging.

The [code of conduct](https://buildguild.gg/code-of-conduct/) applies to every Discussion, pull request and review.
